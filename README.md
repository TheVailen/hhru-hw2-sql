# Продвинутый SQL — Домашнее задание 2

### Инструменты

PostgreSQL, dbdiagram.io.

### О проекте

В рамках заданий исследовал данные IT-вакансий и откликов кандидатов: скорость ответов работодателей, историю звонков и сообщений, различия между компаниями и связь коммуникаций с приглашением на вакансию.

### Итог

Работа позволила сравнить способы и скорость коммуникации работодателей с кандидатами, выявить особенности обработки откликов и проверить связь характеристик общения с приглашением.
Обнаруженные различия носят наблюдательный характер и не доказывают причинно-следственную зависимость.
В ходе работы были применены best practices к написанию продвинутых запросов
